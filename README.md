# duck yeah
chat with GPT and other models in your terminal for free thanks to kind chinese people reversing duck ai api

**Two variants**

| Chat | Server |
| ----------- | ----------- |
| just a chat in your terminal, markdown support | a server that you can send a certain request to, i use it for translation, also markdown support |
| run node ./chat.js and talk | run node ./server.js, it will start on the 13130 port, you can change it ofc  | 
| prefix your message with @ to ask for translation and grammar explanation, type redo to reset the chat | prefix your request's sentence field with @ to ask for translation and grammar explanation, you can also use post.ahk that sends your clipboard with win+ctrl+t shortcut with @ already prefixed  | 

the chinese library is technically in typescript but i dont care all that much, so i used .js. Also if you don't know something you can just take a look at the code, it's very simple
